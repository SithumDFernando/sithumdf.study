# sithumdf.study

> An upcoming interactive study laboratory designed for intuitive, visual learning.

`sithumdf.study` is a digital playground dedicated to making complex, abstract concepts in **computer science**, **mathematics**, and **physics** immediately understandable through real-time, touchable visual simulations. Rather than relying solely on static equations and memorization, each module provides an interactive sandbox to explore cause, effect, and mathematical intuition.

---

## ✨ Features

- **Live Interactive Visualizer**: Real-time canvas simulations including Harmonic Wave Superposition, Keplerian Orbital Gravity, Neural Synapse Networks, and Vector Fields.
- **Warm Light Aesthetic**: Clean layout with warm paper background tones (`#FAF8F5`) and signature terracotta coral accents (`#DE5844`).
- **Interactive Retro Mascot**: An 8-bit alien sprite with 3D flip animation and real-time synthesized retro audio chirps powered by the Web Audio API.
- **Mobile Responsive**: Adaptive navigation, touch-enabled canvas controls (`touch-action: none`), and fluid grid layouts across all screen sizes.
- **CI Pipeline**: Automated build and validation workflow via GitHub Actions for `main` and `dev` branches.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **Visuals & Audio**: HTML5 Canvas API + Web Audio API
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVG

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (Node 20 recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/SithumDFernando/sithumdf_study_v0.git
cd sithumdf_study_v0

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
